# 考试答题工具 (exam-answer-tool)

绍兴职业技术学院管理平台 — 自动答题工具

## 功能

- **PID 检测** — 验证试卷可访问性、获取题型题量
- **答案提取** — 从已有的答题记录(答案页)提取全部答案
- **快速提交** — 一次性提取全部答案并交卷
- **逐题提交** — 每题间隔 10-20 秒，模拟真人答题节奏
- **随机测试** — 随机答题（快速/逐题两种模式）
- **完整浏览器标头** — 从 F12 复制粘贴一次，自动提取 cookie + 21 个标头字段，所有请求完美模拟浏览器

## 操作流程

```
1. F12 → 网络 → 任意请求 → 右键 Copy → 粘贴到输入框
2. 点击「导入标头」 → 自动拆解 cookie + 标头
3. 输入 PID → 「PID 检测」
4. 「获取答案」 → 提取正确答案
5. 「提交(快速/逐题)」或「随机(快速/逐题)」
```

## 项目结构

```
answertools/
├── start.command        # Mac 双击启动
├── main.py              # 主程序(pywebview原生窗口 + HTTP API)
├── config.json          # 配置(PID/参数) — 不提交Git
├── cookie.txt           # Cookie纯文本 — 不提交Git
├── headers.txt          # 原始浏览器标头 — 不提交Git
├── modules/
│   ├── fetcher.py       # 答案提取 + 标头解析
│   ├── checker.py       # PID 检测
│   ├── submitter.py     # 答案提交(快速/逐题) + 随机答题
│   └── __init__.py
└── exam_tool.log        # 运行日志
```

## 按钮说明

| 按钮 | 功能 |
|------|------|
| 导入标头 | 拆解 F12 粘贴的完整请求标头 → cookie + 21个浏览器字段 |
| PID 检测 | 验证试卷可访问性 |
| 获取答案 | 从答案页提取全部正确答案 |
| 随机(快速) | 随机答案立即交卷 |
| 随机(逐题) | 随机答案，每题等 10-20 秒 |
| 提交(快速) | 用正确答案立即交卷 |
| 提交(逐题) | 用正确答案，每题等 10-20 秒 |

## 技术栈

- Python 3.9+
- pywebview (原生窗口)
- urllib (HTTP 请求)
- 无第三方依赖
